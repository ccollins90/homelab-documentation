# Pi-hole notes

Pi-hole is used in this homelab for DNS-based ad and tracker filtering across configured network clients.

Topics worth documenting as the project evolves:
- How clients are configured to use the DNS service
- Blocklist selection and false-positive troubleshooting
- Query-log review and privacy considerations
- Upstream resolver design
- Change validation and rollback steps

Do not publish raw query logs, client names, MAC addresses, or screenshots that identify household devices.
